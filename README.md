# 🧮 Readme del proyecto de la calculadora

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Status](https://img.shields.io/badge/Status-En%20Desarrollo-yellow?style=for-the-badge)
![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)

Este proyecto es una calculadora simple que permite realizar operaciones básicas como suma, resta, multiplicación y división. El código está escrito en Python y se puede ejecutar desde la línea de comandos.

## 📋 Funciones

- [x] **Suma** - `sumar(a, b)` → devuelve a + b 
  ![Enmanuel Madrid](https://img.shields.io/badge/Enmanuel%20Madrid-FF6B6B?style=flat-square) 

- [x] **Resta** - `restar(a, b)` → devuelve a - b  
  ![Andres Jimenez](https://img.shields.io/badge/Andres%20Jimenez-4ECDC4?style=flat-square)

- [x]  **Multiplicación** - `multiplicar(a, b)` → devuelve a * b  
  ![Nicolas Cuellar](https://img.shields.io/badge/Nicolas%20Cuellar-95E1D3?style=flat-square)

- [x]  **División** - `dividir(a, b)` → devuelve a / b (con validación de división por cero)  
  ![Anny Sosa](https://img.shields.io/badge/Anny%20Sosa-F38181?style=flat-square)

- [ ] **Potencia** - `potencia(base, exponente)` → devuelve base^exponente  
  ![Beatriz Ramirez](https://img.shields.io/badge/Beatriz%20Ramirez-AA96DA?style=flat-square)

- [ ] **Porcentaje** - `porcentaje(total, porcentaje)` → devuelve el % de un número  
  ![Diana Varela](https://img.shields.io/badge/Diana%20Varela-FCBAD3?style=flat-square)

- [ ] **Valor Absoluto** - `valor_absoluto(n)` → devuelve |n|  
  ![Jeferson Balaguera](https://img.shields.io/badge/Jeferson%20Balaguera-A8D8EA?style=flat-square)

- [ ] **Promedio** - `promedio(lista_numeros)` → devuelve el promedio de una lista  
  ![Maria Fernanda](https://img.shields.io/badge/Maria%20Fernanda-FFD93D?style=flat-square)

- [x] **Máximo** - `maximo(lista_numeros)` → devuelve el número más grande de una lista  
  ![Natalia Reyes](https://img.shields.io/badge/Natalia%20Reyes-6BCB77?style=flat-square)

- [ ] **Mínimo** - `minimo(lista_numeros)` → devuelve el número más pequeño de una lista  
  ![Samuel Bornacelly](https://img.shields.io/badge/Samuel%20Bornacelly-4D96FF?style=flat-square)

- [ ] **Factorial** - `factorial(n)` → devuelve n! (validar n >= 0)  
  ![Jeimy Ramirez](https://img.shields.io/badge/Jeimy%20Ramirez-FFB6B9?style=flat-square)

- [ ] *Módulo/Resto** - `modulo(a, b)` → devuelve el resto de a/b  
  ![Erika Rodriguez](https://img.shields.io/badge/Erika%20Rodriguez-FEC8D8?style=flat-square)

- [ ] **Es Par** - `es_par(n)` → devuelve True si el número es par, False si es impar  
  ![Francisco Vicisoso](https://img.shields.io/badge/Francisco%20Vicisoso-957DAD?style=flat-square)
