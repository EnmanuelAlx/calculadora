# Readme del proyecto de la calculadora

Este proyecto es una calculadora simple que permite realizar operaciones básicas como suma, resta, multiplicación y divisió- El código está escrito en Python y se puede ejecutar desde la línea de comandos.

tiene estas funciones

- Suma - sumar(a, b) → devuelve a + b, Enmanuel Madrid 👌
- Resta - restar(a, b) → devuelve a - b, Andres Jimenez 
- Multiplicación - multiplicar(a, b) → devuelve a * b, Nicolas Cuellar
- División - dividir(a, b) → devuelve a / b (con validación de división por cero), Anny Sosa
- Potencia - potencia(base, exponente) → devuelve base^exponente, Beatriz Ramirez
- Porcentaje - porcentaje(total, porcentaje) → devuelve el % de un número, Diana Varela
- Valor Absoluto - valor_absoluto(n) → devuelve |n|, Jeferson Balaguera
- Promedio - promedio(lista_numeros) → devuelve el promedio de una lista, Maria Fernanda
- Máximo - maximo(lista_numeros) → devuelve el número más grande de una lista, Nathalia Reyes
- Mínimo - minimo(lista_numeros) → devuelve el número más pequeño de una lista, Samuel Bornacelly
- Factorial - factorial(n) → devuelve n! (validar n >= 0), Jeimy Ramirez
- Módulo/Resto - modulo(a, b) → devuelve el resto de a/b, Erika Rodriguez
- Es Par - es_par(n) → devuelve True si el número es par, False si es impar, Francisco Vicisoso
