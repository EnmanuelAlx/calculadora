# Readme del proyecto de la calculadora

Este proyecto es una calculadora simple que permite realizar operaciones básicas como suma, resta, multiplicación y divisió- El código está escrito en Python y se puede ejecutar desde la línea de comandos.

tiene estas funciones

- Suma - sumar(a, b) → devuelve a + b
- Resta - restar(a, b) → devuelve a - b
- Multiplicación - multiplicar(a, b) → devuelve a * b
- División - dividir(a, b) → devuelve a / b (con validación de división por cero)
- Potencia - potencia(base, exponente) → devuelve base^exponente
- Raíz Cuadrada - raiz_cuadrada(n) → devuelve √n (validar números negativos)
- Porcentaje - porcentaje(total, porcentaje) → devuelve el % de un número
- Valor Absoluto - valor_absoluto(n) → devuelve |n|
- Promedio - promedio(lista_numeros) → devuelve el promedio de una lista
- Máximo - maximo(lista_numeros) → devuelve el número más grande de una lista
- Mínimo - minimo(lista_numeros) → devuelve el número más pequeño de una lista
- Factorial - factorial(n) → devuelve n! (validar n >= 0)
- Módulo/Resto - modulo(a, b) → devuelve el resto de a/b
- Es Par - es_par(n) → devuelve True si el número es par, False si es impar
